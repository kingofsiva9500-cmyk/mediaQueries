# 📱 CSS Media Queries

This repository contains my practice and learning work on **CSS Media Queries**.

## 📚 What I Learned

* What are Media Queries?
* How to make websites responsive
* `min-width` and `max-width`
* Responsive layouts for different screen sizes
* Changing CSS styles based on screen width
* Mobile, tablet, and desktop responsiveness
* Using breakpoints in CSS

## 💻 Example

css
@media screen and (max-width: 768px) {
    .box {
        width: 100%;
    }
}


This allows the CSS to change when the screen width is **768px or smaller**.

The goal of this practice is to understand **Responsive Web Design** and learn how websites
